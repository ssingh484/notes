# LDAP

Was able to use the assumed breach credentials to do a domain dump so able to query ldap via these credentials:

```
└─$ ldapdomaindump 10.0.2.4 -u 'hack-academy.local\lbennett' -p '!!reiD123'
[*] Connecting to host...
[*] Binding to host
[+] Bind OK
[*] Starting domain dump
[+] Domain dump finished
```

This clued me into using bloodhound to see what else I could do from here. Used the docker compose setup to have everything work well for bloodhound ce from [[https://breachar.medium.com/install-bloodhound-ce-under-kali-linux-2024-4-2a68feebdb62]]
